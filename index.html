Privacy controls in this prototype
  • Consent gate before any case is created
  • No name, phone or address fields; anonymous case ID only
  • Data stays in this browser (localStorage); nothing is uploaded to a server except OCR language data
  • Automatic deletion using the timer at the top; manual delete below
  • Role-based view: only Nurse / Doctor see the queue and can override
  • Every action is written to the audit log
